# 좀비서바이벌 게임 - 기능목록

## 코드 구조: MVC 패턴

```
src
├── index.js                     # GameController 연결
├── controller
│   └── GameController.js        # 사용자 행동 처리, Game과 GameView 연결
├── model
│   ├── CardDeck.js              # 카드덱 생성 및 셔플
│   ├── Game.js                  # 카드 뽑기, 날짜 경과, 엔딩 도출, CardDeck과 Player 연결
│   ├── Player.js                # 기본 스탯 관리 및 변경
│   └── cards.js                 # 카드 정보
└── view
    └── GameView.js              # 화면 출력, 버튼 요소 연결
```

### 1. 카드덱 관리 (model/CardDeck.js)

- 카드덱 생성: cards.js에서 각 카드의 정보를 가져와 20장짜리 덱을 생성한다.
- 카드덱 셔플
- 카드 뽑기
- 잔여 카드 수 반환: 게임 화면에 표시한다.

### 2. 플레이어 관리 (model/Player.js)

- 플래이어 생성: 게임 시작 시 플레이어의 초기 상태는 체력 100, 식량 3, 감염도 10, Day 1이며, 치료 횟수와 구조 포인트는 0이다.
- 체력 소모 및 재생: 체력은 0 미만으로 내려가지 않는다.
- 식량 소모 및 획득: 식량은 0 미만으로 내려가지 않는다.
- 감염도 감소 및 증가: 감염도는 0 미만으로 내려가지 않는다.
- 치료횟수 누적
- 구조포인트 누적
- 현재 상태 반환: 게임 화면에 표시한다.

### 3. 게임 관리 (model/Game.js)

- 게임 생성
- 게임 리셋
- 뽑은 카트 저장 및 반환: 매일(Day) 카드 1장을 뽑는다.
- 선택된 카드 선택지 반환: 카드의 선택지 2개 중 1개를 고른다.
- 선택지 효과 적용
- 하루 경과
- 포기 여부 설정: 플레이어는 언제든 게임을 포기할 수 있다.
- 기아 여부 반환: 식량이 없어라는 문구가 포함된 로그를 기록한다.
- 엔딩 반환: 여러 엔딩 조건이 동시에 충족될 경우, 실패 엔딩(사망 / 좀비화)을 성공 엔딩보다 우선 적용한다.
- 게임 화면 표출용 현재 상태 반환
- 앤당 화면 표출용 현재 상태 반환

### 4. 게임 화면 관리 (view/GameView.js)

- 게임 화면, 결과 화면 요소 연결
- 스탯/상태/버튼/카드 요소 연결
- 게임 스탯 표시
- 카드 정보 표시
- 화면 표시
- 카드 뽑기 화면 표시
- 로딩 화면 표시
- 로그 메세지 표시: 게임 시작 시, 카드를 뽑았을 때, 선택지를 골랐을 때, 기아가 발생했을 때 로그를 기록한다.
- 결과 화면 표시: 게임이 종료되면 결과 화면으로 전환되며, 재시작 버튼이 표시된다.
- 화면 초기화: 재시작 시 모든 상태와 로그가 초기화된다.

### 5. 게임 흐름 제어 (controller/GameController.js)

- 게임 시작
- 카드 뽑기
